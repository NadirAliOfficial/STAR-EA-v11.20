# Contributing to STAR-EA-v11.20

Thank you for your interest in contributing!

## Code Guidelines
- Follow clean coding practices and modular architecture.
- Write descriptive commit messages following the Conventional Commits specification.
- Test thoroughly on paper trading or testnets before submitting production PRs.

## Pull Request Process
1. Fork the repository and create your branch from `main`.
2. Ensure all unit and integration tests pass.
3. Submit a Pull Request describing your changes and testing methodology.
